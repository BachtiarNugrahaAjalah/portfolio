# Portofolio Bachtiar Nugraha

Portofolio pribadi modern untuk Bachtiar Nugraha, mahasiswa S1 Ilmu Komputer Universitas Lampung.

## Fitur Utama
- **Desain Modern & Keren**: Tata letak terstruktur dengan identitas visual teknik informatika yang tajam dan profesional.
- **Dual Theme (Dark / Light)**: Mendukung tema gelap (default) dan tema terang dengan toggle interaktif serta penyimpanan preferensi di `localStorage`.
- **Interaktivitas Penuh**: Tombol salin email instan dengan umpan balik visual, menu mobile responsif, tautan sosial lengkap, dan indikator navigasi aktif saat bergulir.
- **Aksesibilitas & Performa Tinggi**: Sesuai standar WCAG AA (kontras rasio tinggi, navigasi keyboard penuh, ramah pembaca layar) dan menggunakan kode murni tanpa beban dependensi eksternal.

## Cara Menjalankan
Buka file `index.html` langsung di browser Anda, atau jalankan server lokal:

```powershell
python -m http.server 8000
```

Buka `http://localhost:8000` di peramban web.
